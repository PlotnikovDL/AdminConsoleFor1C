# Инструкции для разработки

- Коммиты писать на русском языке, в прошедшем времени.
- Основной стек: WinUI 3, C#, .NET, XAML, Windows App SDK, MSIX.
- Подробный стек и архитектурные ориентиры зафиксированы в `docs/technology-stack.md`.
- Перед UI-правками читать `docs/ui-guidelines.md`.
- UI проверять запуском приложения и скриншотом окна, а не только сборкой.
- Для экранов администрирования 1С придерживаться нативного Windows 11 / Fluent-подхода: спокойная рабочая плотность, понятные подписи, стандартные WinUI-контролы.
- Стандартные UI/MVVM-паттерны не писать вручную с нуля: сначала использовать WinUI, Windows Community Toolkit и CommunityToolkit.Mvvm; свой код оставлять для композиции приложения и 1С-специфики.
- Не смешивать без подписи отображаемое имя службы Windows и системное имя службы.
- Порты 1С показывать по назначению: агент, кластер, RAS, отладка HTTP, рабочие процессы.
