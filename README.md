# Admin Console for 1C

Современное Windows-приложение для администрирования служб, кластеров и информационных баз 1С.

## Именование

- Отображаемое имя: `Admin Console for 1C`
- Подзаголовок окна: `Центр администрирования 1С`
- Техническое имя: `AdminConsoleFor1C`
- Исполняемый файл: `AdminConsoleFor1C.exe`

## Пути данных

- Настройки пользователя: `%AppData%\AdminConsoleFor1C`
- Логи: `%LocalAppData%\AdminConsoleFor1C\Logs`
- Общие настройки: `%ProgramData%\AdminConsoleFor1C`

## Правило коммитов

Все коммиты ведутся на русском языке, в прошедшем времени.
