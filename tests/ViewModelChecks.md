# Проверка состояний информационных баз и сеансов

Консольные проекты подключают рабочие исходники ViewModel и CommunityToolkit.Mvvm. Клиенты 1С, хранилище подключений и список служб заменены тестовыми объектами. Из WinUI подменяется только перечисление `InfoBarSeverity`; разметка, привязки и таймеры страницы требуют отдельной проверки запуском приложения.

Запуск из корня репозитория:

```powershell
dotnet run --project tests/AdminConsoleFor1C.InfobaseStateChecks/AdminConsoleFor1C.InfobaseStateChecks.csproj
dotnet run --project tests/AdminConsoleFor1C.SessionStateChecks/AdminConsoleFor1C.SessionStateChecks.csproj
```

Проекты проверяют 41 сценарий ИБ и 22 сценария сеансов: общие и составные фильтры, одинаковые UUID на разных серверах, автоматический выбор кластера и его сервера, ошибки и восстановление, сохранение пользовательского выбора, смену профиля во время чтения и повторные активации страницы. Ошибка сценария даёт ненулевой код завершения. Реальные серверы и службы не изменяются.
