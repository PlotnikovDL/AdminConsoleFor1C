# Центр администрирования 1С 1.2.0

Информационные базы и сеансы теперь используют одинаковые фильтры, автоматически загружают данные при открытии и сохраняют область просмотра при переключении вкладок.

## Изменения

- Одинаковые фильтры «Сервер → Кластер → База → Поиск» в информационных базах и сеансах, включая общие списки «Все».
- Автоматическая загрузка при первом открытии раздела и обновление сохранённой области при возвращении на вкладку. Фильтры сохраняются до закрытия приложения.
- Единая команда «Обновить». Периодическое обновление работает только на открытой вкладке.
- Локальные подключения идут перед удалёнными, порты одного компьютера — по возрастанию.
- Выбор кластера подставляет его сервер; выбор сервера с единственным подтверждённым кластером подставляет этот кластер.
- Согласованы имена локальных подключений, версии платформы и сопоставление процессов со службами.
- Сеансы проверяют фактическую версию агента перед чтением и завершением; недоступные подключения не оставляют устаревшие строки для действий.
- При удалении службы очистка каталога данных по умолчанию выключена.

Редактор параметров существующей информационной базы ещё не реализован в интерфейсе и в возможности этой сборки не входит.

## Установка

Закройте приложение и запустите `AdminConsoleFor1C-1.2.0-win-x64-setup.exe`. Установщик обновляет предыдущую версию; сохранённые подключения остаются в профиле пользователя. Для переноса на другой компьютер достаточно файла установщика.

.NET и Windows App SDK входят в установщик. Компоненты платформы 1С (`rac.exe` и `ras.exe`) устанавливаются отдельно. После запуска в заголовке окна должна отображаться версия 1.2.0.

Обновление WinGet отправлено на проверку в [заявке №448261](https://github.com/microsoft/winget-pkgs/pull/448261). До завершения публикации устанавливайте 1.2.0 из EXE этого релиза; в каталоге WinGet пока доступна 1.1.1.

## Проверка

Прошли 185 модульных тестов и 63 сценария рабочих ViewModel (41 для информационных баз, 22 для сеансов). Проверены состав автономного комплекта, запуск приложения и загрузка .NET/Windows App SDK из каталога приложения. Окно версии 1.2.0 проверено по снимку штатного теста запуска.

Проверки чтения и фильтров не создают базы, не завершают пользовательские сеансы и не изменяют службы. Команды изменения данных проверяются с подменой транспорта.
