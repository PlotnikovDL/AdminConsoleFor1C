# Центр администрирования 1С 1.1.1

Создавайте пустые серверные базы с явным выбором сервера 1С, версии платформы и кластера. Зарегистрированные локальные службы теперь появляются в списке серверов автоматически.

## Что изменилось

- Добавлен раздел «Информационные базы»: список баз, поиск, выбор сервера и кластера, создание пустой базы.
- Добавлена форма параметров СУБД с итоговой проверкой перед созданием. Доступны язык, смещение дат, защищённое соединение, регламентные задания и выдача лицензий.
- Перед созданием проверяются фактическая версия агента, выбранный кластер и отсутствие базы с таким именем. При неопределённом результате команды повторное создание блокируется до проверки состояния базы.
- Новая локальная служба агента появляется в выборе сервера без ручного добавления подключения. Для каждой службы показаны порт, версия и состояние; сохранённые удалённые подключения остаются доступны.
- В параметрах подключения появился выбор установленной версии платформы.
- Версия приложения показана в заголовке окна. У отладочной сборки есть отметка «Разработка».

## Установка и обновление

Скачайте **AdminConsoleFor1C-1.1.1-win-x64-setup.exe**, закройте консоль и запустите установщик поверх предыдущей версии. Сохранённые подключения сохранятся. Контрольная сумма SHA256 приложена отдельным файлом.

Windows x64, начиная с Windows 10 2004. .NET и Windows App SDK включены в установщик. Компоненты платформы 1С устанавливаются отдельно. EXE пока не имеет доверенной цифровой подписи.

Версия 1.1.1 опубликована в WinGet: [заявка №435995](https://github.com/microsoft/winget-pkgs/pull/435995) одобрена и принята 30 сентября 2026 года, публикация завершилась успешно.

## Проверка

Пройдены 122 автоматических теста. На Windows 11 проверены запуск автономной сборки, интерфейс, обнаружение локальной службы, соответствие версии агента и выбор кластера. Отправка команды создания базы и обработка ошибок проверены автоматическими тестами с подменой транспорта.

Создание из шаблонов конфигураций и файловые базы в этот выпуск не входят.
